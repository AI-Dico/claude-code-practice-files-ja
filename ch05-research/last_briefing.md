# 会議室の予約方法の見直し — 報告書（1ページ）

報告: 総務 → 部長 / 2026-08-28

結論から言うと、会議室の予約は共有カレンダー1つで十分です。根拠は2つあります。

1つ目は、二重予約がなくなることです。今の紙の予約表では、8月だけで3件の二重予約がありました。共有カレンダーなら、同じ時間に2件目を入れようとした時点で気づけます。

2つ目は、費用がかからないことです。すでに全員が使っているカレンダーに会議室を追加するだけなので、新しいツールの契約も、使い方の研修もいりません。

想定される質問: 「カレンダーを使わない人はどうするのか？」→ 総務が代わりに入力します。8月の予約のうち、紙だけで申し込んだのは2件でした。
