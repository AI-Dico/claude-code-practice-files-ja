# Claude Code 練習用ファイル（日本語版）

**👉 https://github.com/AI-Dico/claude-code-practice-files-ja**

YouTube「Dico」の Claude Code 基礎編シリーズで使う、練習用ファイルの置き場です。
文書・表・レシート・契約書まで、**すべて架空のデータ**です。カード明細に出てくるお店の名前も、実際の取引ではなくプログラムで作ったニセの明細です。安心して、思いきり試してください。

---

## ダウンロードのしかた（はじめての方へ）

1. このページの右上にある緑色の **Code ▾** ボタンを押します。
2. いちばん下の **Download ZIP** を押します。
3. ダウンロードした ZIP ファイルを開いて（ダブルクリックで）展開します。`claude-code-practice-files-ja-main` というフォルダができます。
4. フォルダ名の最後の `-main` を消して `claude-code-practice-files-ja` に変え（右クリック → 名前を変更）、**デスクトップ**のような見つけやすい場所に置いてください。この先の説明は、すべてこの名前で書いています。

> 補足: `git clone` という方法もありますが、知らなくても大丈夫です。「頼み方の回」を見終えた方は、Claude Code に「このアドレスのファイルを持ってきて」と頼んでもかまいません。

## はじめかた — `cd` と `claude`、2行だけです

1. **ターミナルを開きます。**
   - Mac: `Cmd + Space` →「ターミナル」と入力 → Enter
   - Windows: スタートメニューから **Ubuntu** を探して開きます（インストールの回で入れた WSL の画面です。ふつうの PowerShell の画面ではうまく動きません）
2. **練習用のフォルダに移動します。** たとえば「数字を任せる回」なら:
   ```
   cd ~/Desktop/claude-code-practice-files-ja/ch04-numbers
   ```
   > Windows（WSL）では `cd /mnt/c/Users/あなたのユーザー名/Desktop/claude-code-practice-files-ja/ch04-numbers` のように、場所の書き方が少し変わります。フォルダを置いた場所に合わせてください。
3. **Claude Code を起動します。**
   ```
   claude
   ```
4. `>` の入力欄が出たら、AI社員の出勤完了です。

**フォルダに移動して claude を起動する。これがもう最初の練習です。**

|----------|----------------|--------|------|

| `ch02-how-to-ask/` | 議事録 `minutes.txt`、アンケート結果 `survey-results.csv`、調査メモ `research/`（3個） | 頼み方の回 | （公開後にリンクを追加） |
| `ch03-files/` | 文書30個（`materials/`）、報告書のひな形 `my-template.md`、契約書 `contract_sample.pdf`、レシートの写真（`receipts/` 3枚） | ファイルを任せる回 | （公開後にリンクを追加） |

| `ch05-research/` | 前回の報告書の見本 `last_briefing.md` | 調べものを任せる回 | （公開後にリンクを追加） |

| `ch07-repeat/` | 「数字を任せる回」を終えた状態のファイル一式 + 形式の崩れたデータ `bad-data.csv` | 繰り返しを減らす回 | （公開後にリンクを追加） |

「困ったときの回」には専用のフォルダはありません。どのフォルダでも試せます。

### ch07 は少し特別です

`ch07-repeat/` は、**「数字を任せる回」を終えたあとの状態を先に作っておいたフォルダ**です。
「数字を任せる回」を飛ばしていても、すぐに「繰り返しを減らす回」の練習ができます。
動画の画面に合わせて、ファイル名は `card.csv`（3〜8月）、`2026-10_card.csv`（10月）、`spending.md` / `spending.html`（分析レポート）になっています。

### 金額とファイルの形式について

- 金額はすべて円です。動画の画面に出てくる数字と同じになるように作ってあります（例: 6か月の合計 2,634,984円）。
- CSV ファイルは UTF-8（BOM付き）で保存しています。エクセルで開いても文字化けしません。
- ファイル名・フォルダ名は、ターミナルで打ちやすいようにすべて英語にしています。中身は日本語です。
